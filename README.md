# Small Office Network Design and VLAN-Based Segmentation

## Project Overview
Designed and simulated a small office network using Cisco Packet Tracer, implementing VLAN-based segmentation to separate HR and IT departments and manage network communication.

## Technologies and Concepts
- Cisco Packet Tracer
- Cisco 2960 Switch
- Cisco Router
- VLAN Configuration
- IEEE 802.1Q Trunking
- Router-on-a-Stick
- Inter-VLAN Routing
- DHCP Configuration
- IPv4 Addressing

## Network Design
The network consists of two departments:
- HR Department – VLAN 10 (192.168.10.0/24)
- IT Department – VLAN 20 (192.168.20.0/24)

## Implementation
1. Designed the office network topology using a router, switch and end devices.
2. Created separate VLANs for HR and IT departments.
3. Assigned switch access ports to their respective VLANs.
4. Configured trunk communication between the switch and router.
5. Configured router subinterfaces for inter-VLAN routing.
6. Configured DHCP for automatic IP address allocation.
7. Tested connectivity between devices and across VLANs.

## Key Learning Outcomes
- Understanding VLAN-based network segmentation.
- Configuring switch access ports and trunk links.
- Implementing inter-VLAN routing using router subinterfaces.
- Configuring DHCP for client devices.
- Verifying network connectivity.
